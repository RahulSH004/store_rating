# StoreRate

StoreRate is a full-stack store-rating platform. Users can browse stores and submit ratings, while administrators and store owners get role-based management and dashboard views.

## Stack

- **Frontend:** React, TypeScript, Vite, Axios, React Router
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL with Prisma ORM
- **Authentication:** JWT with role-based access control

## Features

- User registration, login, logout, and password updates
- Role-based access for users, administrators, and store owners
- Store browsing and administration
- Rating submission and user-specific rating display
- Admin, store-owner, and user-facing dashboard flows
